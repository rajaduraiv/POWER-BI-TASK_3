# Power BI Task

## 1. Project Title

**Shopify Stock Data Analysis using Power BI**

## 2. Objective

The objective of this Power BI task is to import, organize, model, and visualize Shopify stock-related data. The report uses Power BI to present data in an understandable format and allows the user to analyze information based on different fields such as date and month.

## 3. Tool Used

* **Microsoft Power BI Desktop**
* **Power Query** for data preparation
* **Data Model** for organizing tables and relationships
* **Report View** for creating visualizations

## 4. Dataset / Tables Used

The Power BI file contains the following tables:

### Shopify Stock

This is the main stock-related table used for the report.

### Dim_Date

This is a date dimension table used for date-based analysis. The Month field from this table is used in the report visualization.

## 5. Operations Performed

The following operations were performed in the Power BI task:

### 5.1 Data Import

The Shopify stock data was imported into Power BI for analysis.

### 5.2 Data Preparation

The available data was organized and prepared for use in the Power BI report.

### 5.3 Date Dimension

A **Dim_Date** table was included in the data model to support date-related analysis.

### 5.4 Data Model

The tables were added to the Power BI data model so that the data could be used for report analysis and visualization.

### 5.5 Month Analysis

The **Month** field from the **Dim_Date** table was selected for visualization.

### 5.6 Table Visualization

A table visual was created to display the Month information from the Dim_Date table.

### 5.7 Filtering

The report supports categorical filtering using the Month field. This allows the displayed information to be filtered according to the selected month.

### 5.8 Drill/Filter Interaction

The report is configured to allow visual interactions and filtering between report elements.

### 5.9 Report Page Formatting

The report page was configured using **Fit to Page**, allowing the report content to fit within the available report area.

### 5.10 Report Theme

The Power BI **Fluent 2** theme is applied to the report.

### 5.11 Data Export/Summarization

The report settings allow summarized data to be exported where applicable.
